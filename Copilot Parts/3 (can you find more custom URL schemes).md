Sure! Here are some examples of custom URL schemes used by various applications:

- **mailto**: Opens the user's default email client with a pre-filled email address.
- **tel**: Initiates a phone call to a specified number.
- **sms**: Sends a text message to a specified number.
- **facetime**: Opens FaceTime with a specified phone number or email address.
- **ms-word**: Opens a document in Microsoft Word.
- **ms-excel**: Opens a document in Microsoft Excel.
- **ms-powerpoint**: Opens a presentation in Microsoft PowerPoint.
- **msteams**: Opens Microsoft Teams.
- **freeplane**: Opens a Freeplane mind map file.
- **geo**: Opens a specific geographic location in a maps application.
- **app**: Used by packaged applications to obtain resources inside a container.

Custom URL schemes allow applications to be launched with specific context data, making it easier to integrate and interact with other apps and services. If you have a specific use case in mind, I can help you find or create a custom URL scheme for it!
